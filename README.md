# .NET MAUI Samples

Este repositório reúne projetos de exemplo e pequenos desenvolvimentos utilizando **.NET MAUI**, com o objetivo de aprendizado, experimentação e demonstração de recursos da plataforma.

Aqui você encontrará aplicações simples que servem como ponto de partida para explorar conceitos e práticas com o **.NET MAUI**.  
Cada projeto tem um foco específico e será documentado logo abaixo na seção Projetos ainda nesta página.

---

## Projetos

### 🎲 AppLuckNumber
- **Descrição:**  
  O AppLuckNumber permite gerar números da sorte de forma simples e rápida. É um primeiro contato com a criação de telas, eventos e interação básica com o usuário em .NET MAUI.

- **Funcionalidades:**  
  - Geração de números aleatórios  
  - Interface simples 
  - Demonstração prática de uso de botões e exibição de resultados
  - Exibição dinâmica de dados na interface
